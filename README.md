# Student-Management-System-Project-for-SQL-Developers
The project focuses on providing students with practical experience in SQL database creation, data manipulation, and analysis using student performance data.

# Description of this Project 
Developed a Student Management System using SQL to store and analyze student academic data. The project includes database creation, table design, data insertion, and analytical queries to evaluate student performance. Key analyses include subject-wise average scores, top performers, grade distribution, gender-based performance comparison, identification of high achievers in Mathematics, and record updates. This project demonstrates practical usage of SQL concepts such as DDL, DML, aggregate functions, filtering, grouping, sorting, subqueries, and data manipulation.

# Key Features
1.Database and table creation using SQL
2.Student data management
3.Subject-wise performance analysis
4.Top performer identification
5.Grade distribution analysis
6.Gender-based score comparison
7.High achiever detection
8.Student record updates and verification
9.Use of Aggregate Functions (AVG, COUNT, MAX)
10.Data filtering with WHERE
11.Grouping and sorting using GROUP BY and ORDER BY
